    - If next node is terminal (no choices), return node with empty choices (UI shows Farewell)

  c. `dialogue:getAvailableNpcs` handler (portId: string):
    - Scan dialogue files for matching port_id
    - Build GameContext from DB
    - For each matching NPC file, check if entry node conditions are met
    - Return `Array<{ npcId: string, name: string }>` (name from first node's speaker field)
