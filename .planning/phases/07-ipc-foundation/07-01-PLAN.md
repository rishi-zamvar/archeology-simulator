- Export type `LogLevel = 'debug' | 'info' | 'warn' | 'error'`
- Export interface `Logger` with methods: `debug(msg: string, ctx?: Record<string, unknown>): void`, `info(...)`, `warn(...)`, `error(...)`
- Export `createLogger(module: string): Logger` factory function
- Log format: `[2026-03-17T12:00:00.000Z] [ModuleName] INFO: message {"key":"value"}`
  - Timestamp: `new Date().toISOString()`
  - Module: the string passed to createLogger, right-padded to 12 chars for alignment
  - Level: uppercase, right-padded to 5 chars (DEBUG, INFO , WARN , ERROR)

**src/shared/ipc-types.ts** — Add the IPCResponse discriminated union.

Add near the top of the file (after existing imports, before IPCBridge):

```typescript
/**
 * Discriminated union returned by every IPC handler.
 * Handlers NEVER return raw values or throw — always return IPCResponse<T>.
 */
export type IPCResponse<T> =
  | { success: true; data: T }
  | { success: false; error: string };
```

Do not change any other existing types in this file — additive only.

**src/main/lib/ipc-wrapper.ts** — Higher-order function that enforces the IPC contract.

Requirements:
- Import `ipcMain` from electron
- Import `IPCResponse` from `../../shared/ipc-types`
- Import `createLogger` from `./logger`
- Create a module-level logger: `const log = createLogger('IPCWrapper')`
- Export type `Validator<A extends unknown[]> = (...args: A) => string | null` — returns error string or null if valid
- Export function `wrapHandler<T, A extends unknown[]>` with signature:
  ```typescript
  function wrapHandler<T, A extends unknown[] = []>(
    channel: string,
    handler: (...args: A) => T | Promise<T>,
    validator?: Validator<A>
  ): void
  ```
- Implementation:
  1. Call `ipcMain.handle(channel, async (_event, ...args: A): Promise<IPCResponse<T>> => { ... })`
  2. If `validator` provided: call `validator(...args)` — if it returns a non-null string, return `{ success: false, error: validationError }`
  3. Wrap `handler(...args)` in try/catch
  4. On success: return `{ success: true, data: await handler(...args) }`
  5. On catch: log `log.error('Handler failed', { channel, error: err instanceof Error ? err.message : String(err) })` then return `{ success: false, error: err instanceof Error ? err.message : String(err) }`
- The wrapper is the ONLY place ipcMain.handle is called — handlers themselves are pure async functions
- JSDoc the function explaining the contract
