Update every renderer call site to unwrap the IPCResponse envelope. The pattern is consistent: check `.success`, extract `.data` on success, handle `.error` on failure.

**Standard unwrap pattern for hooks:**
```typescript
const response = await window.api.game.someMethod(args);
if (!response.success) throw new Error(response.error);
return response.data; // now typed correctly
```

**Standard unwrap pattern for fire-and-forget (.catch style):**
```typescript
window.api.game.someMethod().then((res) => {
  if (!res.success) return; // or log the error
  // use res.data
}).catch(() => { /* network/IPC failure */ });
```

**File-by-file changes:**

**useGameState.ts:**
- `load()` call: `const response = await window.api.game.load(); if (!response.success) throw new Error(response.error); setState(response.data);`
- `action()` call in updateGame: `const response = await window.api.game.action(action); return response;` — GameResult is now inside IPCResponse as `response.data`, but `updateGame` currently returns `GameResult`. Change the return type to `Promise<IPCResponse<GameResult>>` and return the full response. Update `UseGameStateReturn` interface accordingly.

**useMapPorts.ts:**
- `getPorts()` call: unwrap response, `setPorts(response.data)`, on failure set error

**useTradeState.ts:**
- The `Promise.all` call fetches getMarketPrices, getPlayerInventory, getTransactionHistory
- Change to: `const [goodsRes, invRes, txnRes] = await Promise.all([...]); if (!goodsRes.success || !invRes.success || !txnRes.success) { throw new Error(goodsRes.error ?? invRes.error ?? txnRes.error ?? 'IPC error'); } setMarketGoods(goodsRes.data); setInventory(invRes.data); setTransactions(txnRes.data);`

**useResourceImages.ts:**
- `scanResourceImages()` call: check success, use `result.data.ports` and `result.data.goods`

**useArtifactImages.ts:**
- `Promise.all` over `getArtifacts`: each result is `IPCResponse<CachedArtifact[]>` — extract `.data` (or `[]` on failure)
- `goodIds.forEach((id, idx) => map.set(id, results[idx]?.data ?? []))`

**Shell.tsx:**
- `getPorts()` then: check `res.success`, use `res.data` (the Port array) where `ports` was used
- `getPendingEvent()` then: check `res.success`, use `res.data`
- `buyGood(...)` and `sellGood(...)` awaits: check `res.success`, throw or ignore based on existing error handling pattern (currently no error handling — add `if (!res.success) console.warn(...)` at minimum using log from a renderer logger instance, or just check silently)
- `game.action(...)` void calls (handleNavigate, other fire-and-forget): these return `IPCResponse<GameResult>` — since they are void/ignored, just `.catch()` is fine, the response object itself can be ignored

**ShipMarker.tsx:**
- `window.api.game.action({ type: 'ARRIVE' }).then(() => window.api.game.action(...))` — both now return `IPCResponse<GameResult>`. Chain becomes: `.then((res) => { if (res.success) return window.api.game.action(...); }).then((res) => { /* existing continuation */ })`

**MapArea.tsx:**
- `window.api.game.action({ type: 'START_TRADE', port: portId }).catch(...)` — response is `IPCResponse<GameResult>`, the .catch() still covers thrown exceptions. The resolved response can be ignored here (fire-and-forget).

**TutorialModal.tsx:**
- Two `window.api.game.action(...)` calls with `.catch(() => {})` — change to `.then((res) => { if (!res.success) { /* log */ } }).catch(() => {})` — but since these are fire-and-forget the simplest fix is to leave `.catch()` and ignore the response value. The TypeScript type is satisfied because the promise resolves without throwing.

**PortInfoPanel.tsx:**
- `Promise.all([getPortDetails(portId), getReachablePorts(portId)])` — both return `IPCResponse<T>`. Unwrap each: `const [detailRes, reachableRes] = await Promise.all([...]); if (!detailRes.success) throw ...; if (!reachableRes.success) throw ...; // use detailRes.data and reachableRes.data`

**EventCard.tsx:**
- `resolveEvent(event.id, choiceId)` — currently checks `response.success` already. New shape: `IPCResponse<{ outcome: EventOutcome; message: string }>`. Update to: `if (!response.success) { /* show error */ return; } const { outcome, message } = response.data;`
