**Step A — Add image:download-approved handler to src/main/ipc/game.ts:**

1. Accepts an array of approved candidate objects:
   ```typescript
   interface ApprovedImage {
     id: string;           // from candidate (e.g., "met_grain_12345")
     portId?: string;      // for port images
     goodId?: string;      // for good images
     imageUrl: string;     // direct image URL to download
     title: string;
     attribution: string;
     sourceUrl: string;
   }
   ```

2. For each approved image, determine destination file path:
   - Port images: `resources/images/ports/{portId}.jpg` (or .png if URL ends in .png)
   - Good images: `resources/images/{goodId}/{goodId}_{1..N}.jpg` — N is the 1-based index within that good's approved list

3. Download each image using this safe pattern. Use Node 18+ built-in `fetch` — no import needed:
   ```typescript
   // Compute absolute dest path using same dev/prod branch as existing game.ts IPC handler
   const tmpPath = `${destPath}.tmp`;
   const resp = await fetch(imageUrl, {
     headers: { "User-Agent": "ArcheologySimulator/1.1" },
     signal: AbortSignal.timeout(30000)
   });
   if (!resp.ok || !resp.headers.get("content-type")?.startsWith("image/")) {
     throw new Error(`Bad response: ${resp.status}`);
   }
   // Stream to tmp file
   const buffer = Buffer.from(await resp.arrayBuffer());
   if (buffer.byteLength === 0) throw new Error("Empty file");
   await fs.promises.writeFile(tmpPath, buffer);
   await fs.promises.rename(tmpPath, destPath); // atomic on success
   ```
   Clean up tmpPath on any error (catch + unlink if exists). Do NOT write to manifest on failure.

4. After ALL downloads succeed for a given image, append one record to `resources/data/curated-images.json`:
   ```json
   {
     "id": "{approved.id}",
     "portId": "{approved.portId or omit}",
     "goodId": "{approved.goodId or omit}",
     "filePath": "resources/images/ports/{portId}.jpg",
     "attribution": "{approved.attribution}",
     "sourceUrl": "{approved.sourceUrl}",
     "createdAt": "{ISO timestamp}"
   }
   ```
   Read the current manifest, push the new record, write back with JSON.stringify(manifest, null, 2). Skip if id already exists in manifest (idempotent).

5. Return `{ succeeded: string[], failed: string[] }` listing image IDs that succeeded or failed.

The handler should process images sequentially (not in parallel) with a 500ms pause between downloads to avoid rate-limiting.
