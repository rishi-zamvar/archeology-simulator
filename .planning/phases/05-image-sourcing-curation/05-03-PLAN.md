  <action>
Process each of the 8 trade goods ONE AT A TIME. For each good, find and curate up to 4 images (minimum 1). Process goods in order from easiest to hardest availability.

**Process order:** wine, pottery, olive_oil, wheat, textiles, bronze, timber, spices

**For EACH trade good, repeat for EACH image slot (up to 4):**

**STEP 1 - Search for candidates:**
Use WebSearch to find 2-3 candidate ancient art images per slot. Images MUST be ancient art (mosaics, frescoes, vase paintings, reliefs, ancient sculptures) -- NOT modern photos, NOT illustrations/paintings.

Suggested search queries:

| Good | Primary Search | Backup Search |
|------|---------------|---------------|
| wine | `"Dionysus wine" mosaic OR fresco OR "vase painting"`, `"ancient grape harvest" mosaic fresco` | `"Roman wine" mosaic Pompeii`, `"Greek symposium" vase painting` |
| pottery | `"ancient potter workshop" vase painting`, `"Greek potter wheel" painting` | `"ceramic workshop" ancient art`, `"Attic potter" vase` |
| olive_oil | `"ancient olive harvest" mosaic OR fresco`, `"Greek olive oil" amphora vase painting` | `"olive press" ancient relief`, `"Roman olive" mosaic` |
| wheat | `"Roman wheat harvest" mosaic`, `"Ceres grain" fresco` | `"ancient wheat sheaves" relief`, `"Egyptian grain harvest" relief` |
| textiles | `"Penelope weaving" vase painting`, `"ancient loom" fresco mosaic` | `"Roman textile" mosaic`, `"Greek weaving" vase` |
| bronze | `"Greek metalworking" vase painting`, `"ancient bronze workshop" relief` | `"bronze smithing" ancient art`, `"Hephaestus forge" vase` |
| timber | `"ancient shipbuilding" relief`, `"Lebanese cedar transport" Egyptian relief` | `"timber trade" ancient art`, `"Egyptian woodworking" relief` |
| spices | `"ancient spice trade" relief mosaic`, `"frankincense" ancient art` | `"Roman spice merchant" mosaic`, `"incense offering" ancient relief` |

Also try Met Museum API for each good:
```bash
curl "https://collectionapi.metmuseum.org/public/collection/v1/search?q=ancient+{good}+{medium}&isPublicDomain=true"
```

**STEP 2 - Download candidates to temp:**
```bash
curl -L -o /tmp/{goodId}_slot{N}_candidate_1.jpg "IMAGE_URL"
file --mime-type /tmp/{goodId}_slot{N}_candidate_1.jpg
```

**STEP 3 - Present candidates to user (CHECKPOINT):**
Present candidates for one image slot at a time:

```
=== TRADE GOOD: Wine (wine) — Image 1 of 4 ===

Candidate 1: [title/description]
Source: [URL]
Attribution: [artist/origin, date, medium]
Why chosen: [why this depicts wine appropriately]
[Show image via Read tool]

Candidate 2: ...
```

Ask: "Pick a number, or 'none' for new search, or 'skip' to move to next good."

**STEP 4 - Save approved image:**
```bash
cp /tmp/{goodId}_slotN_candidate_X.jpg resources/images/{goodId}/{goodId}_{NN}.jpg
rm /tmp/{goodId}_slot*
```

Numbering: 01, 02, 03, 04 sequentially per good.

**STEP 5 - Update manifest incrementally:**
After each GOOD is complete (all its image slots filled or skipped), append entries to curated-images.json immediately. Do not wait until all 8 goods are done.

Entry format:
```json
{
  "id": "good-wine-01",
  "goodId": "wine",
  "filePath": "images/wine/wine_01.jpg",
  "attribution": "[Description], [Date], [Origin/Museum]",
  "sourceUrl": "[URL]"
}
```
