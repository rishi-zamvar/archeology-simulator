  <name>Task 1: Add image:search-port-candidates IPC handler</name>
  <files>src/main/ipc/game.ts, src/shared/ipc-types.ts</files>
  <action>
Add a new IPC handler `image:search-port-candidates` to src/main/ipc/game.ts that:

1. Accepts `{ portId: string }` where portId is one of: alexandria, carthage, rome, athens, antioch
2. Uses these search terms per port (compound historical terms — do NOT use generic terms):
   - alexandria: "Alexandria harbor Pharos ancient Egypt illustration"
   - carthage: "Carthage Cothon harbor ancient Phoenician North Africa"
   - rome: "Ostia harbor Roman port ancient city illustration"
   - athens: "Piraeus harbor ancient Greece Aegean illustration"
   - antioch: "Antioch Orontes ancient Levant Syria city"
3. Searches Met Museum first:
   - GET https://collectionapi.metmuseum.org/public/collection/v1/search?q={term}&hasImages=true&isPublicDomain=true
   - Fetch detail for each objectID (skip first 2, sample up to 8 IDs spaced every other one)
   - Gate per detail: obj.isPublicDomain === true AND obj.primaryImage?.trim() non-empty
   - Collect up to 3 valid candidates from Met
4. If Met returns fewer than 1 candidate, fallback to Wikimedia Commons:
   - GET https://commons.wikimedia.org/w/api.php?action=query&list=search&srsearch={term}&srnamespace=6&srlimit=10&format=json&origin=*
   - Build candidate from search result (sourceUrl = wiki file page, imageUrl = result.url if present, attribution = "Wikimedia Commons")
   - Filter out results with "modern", "20th", "diagram", "photograph" in title
   - Collect up to 2 Wikimedia candidates
5. Return `ImageCandidate[]` where:
   ```typescript
   interface ImageCandidate {
     id: string;           // "met_alexandria_12345" or "wiki_athens_67890"
     portId: string;       // "alexandria" etc.
     sourceUrl: string;    // clickable museum page URL (for user to verify)
     imageUrl: string;     // direct image URL (for preview display)
     title: string;
     attribution: string;  // museum-provided or "Wikimedia Commons"
     source: "met" | "wikimedia";
   }
   ```
6. Add sequential 1-second delays between Met detail API calls (do not fire in parallel) to avoid hammering the API.
7. Register handler in ipc/game.ts and expose the ImageCandidate type in src/shared/ipc-types.ts.

Do NOT implement download logic here. This handler only searches and returns candidates.

Error handling: if Met search fails entirely, log the error and proceed to Wikimedia. If both fail, return empty array (don't throw).
