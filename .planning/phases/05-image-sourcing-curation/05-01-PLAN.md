  <files>resources/images/ports/athens.jpg, resources/images/ports/corinth.jpg, resources/images/ports/sparta.jpg, resources/images/ports/miletos.jpg, resources/images/ports/ephesos.jpg, resources/images/ports/byzantion.jpg, resources/images/ports/rhodes.jpg, resources/images/ports/knossos.jpg, resources/data/curated-images.json</files>
  <action>
Process each of the 8 Greek ports ONE AT A TIME using this workflow. Maintain a running list of manifest entries as you go.

**Port list (in order):** athens, corinth, sparta, miletos, ephesos, byzantion, rhodes, knossos

**For EACH port, repeat this cycle:**

**STEP 1 - Search for candidates:**
Use WebSearch to find 2-3 candidate illustrations. These MUST be drawn/illustrated scenes (paintings, engravings, etchings, sketches) -- NOT photographs of ruins.

Suggested search queries by port:
- athens: `"Piraeus harbor" OR "port of Piraeus" painting OR engraving ancient`
- corinth: `"ancient Corinth" OR "Lechaion harbor" illustration OR painting`
- sparta: `"ancient Sparta" OR "Gythion harbor" illustration painting` (Sparta is inland; Gythion was its port)
- miletos: `"ancient Miletus" OR "Miletos harbor" illustration painting reconstruction`
- ephesos: `"ancient Ephesus" OR "Ephesos harbor" painting illustration engraving`
- byzantion: `"ancient Byzantium" OR "Constantinople harbor" OR "Golden Horn" painting engraving`
- rhodes: `"ancient Rhodes harbor" OR "Colossus of Rhodes" painting illustration` (Colossus depictions often include the harbor)
- knossos: `"ancient Knossos" OR "Minoan Crete" OR "Knossos palace" illustration painting`

If initial search yields poor results, try:
- Alternative names (modern city names, regional names)
- Broader terms: "[region] ancient port illustration"
- Source-specific: search Wikimedia Commons, Met Museum API, Artvee directly

**STEP 2 - Download candidates to temp:**
```bash
curl -L -o /tmp/{portId}_candidate_1.jpg "IMAGE_URL"
file --mime-type /tmp/{portId}_candidate_1.jpg  # Must be image/*, not text/html
ls -la /tmp/{portId}_candidate_1.jpg  # Must be > 1KB
```

For Wikimedia Commons: extract the actual file URL from the File: page (the full-resolution URL from `upload.wikimedia.org`), not the thumbnail.
For Met Museum API: use the `primaryImage` field from the object endpoint.

**STEP 3 - Present candidates to user (CHECKPOINT):**
Use the Read tool to display each candidate image inline. Present as numbered list:

```
=== PORT: Athens (athens) ===

Candidate 1: [title/description]
Source: [URL]
Attribution: [artist, date, medium]
Why chosen: [brief note on relevance]
[Show image via Read tool]

Candidate 2: ...
```

Ask: "Pick a number, or 'none' for a new search."

**STEP 4 - Finalize approved image:**
```bash
cp /tmp/{portId}_candidate_N.jpg resources/images/ports/{portId}.jpg
rm /tmp/{portId}_candidate_*.jpg
```

Record the manifest entry for this port (keep in memory until Task 2).

**FALLBACK RULES:**
- If 2 search rounds yield nothing suitable, use AI image generation in 18th-19th century engraving style depicting the ancient port. Tool choice is at executor discretion.
- Ports most likely to need fallback: sparta (inland city), miletos, knossos (palace, not port)
- If user says "none" twice, move to AI generation immediately.

**IMPORTANT:** Process ports sequentially. Do NOT batch all searches upfront. The user needs to see and approve one port at a time to avoid decision fatigue.

- `attribution`: include artist name (or "Unknown Artist"), approximate date, source collection
- `sourceUrl`: the original page URL (not the direct image URL)

Write updated JSON array back, pretty-printed with 2-space indent.

If the manifest already has entries (from a prior interrupted run), APPEND -- do not overwrite existing entries.
