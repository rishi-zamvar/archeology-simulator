**P&L calculation (per TRD-01, TRD-02):**
```typescript
// Inside the marketGoods.map() callback, after `const carried = getCarried(good.id);`
const cargoForGood = inventory.cargoItems.filter(c => c.goodId === good.id);
const totalQty = cargoForGood.reduce((s, c) => s + c.quantity, 0);
const totalCost = cargoForGood.reduce((s, c) => s + c.quantity * c.boughtAtPrice, 0);
const avgPurchasePrice = totalQty > 0 ? totalCost / totalQty : 0;
const profitPerUnit = good.currentPrice - avgPurchasePrice;
const totalPL = profitPerUnit * qty; // qty is the selected sell quantity
```

**P&L display (TRD-01):**
Below the "Carrying: X" div, when `carried > 0`, render:
```tsx
<div style={{
  ...SUBTEXT,
  fontSize: '0.7rem',
  color: profitPerUnit > 0 ? '#2b5c4a' : profitPerUnit < 0 ? '#8b2e2e' : '#7a5c45',
  fontWeight: 600,
  marginBottom: '0.15rem',
}}>
  {profitPerUnit > 0 ? '+' : ''}{Math.round(profitPerUnit)}g/unit
  {' '}({profitPerUnit > 0 ? '+' : ''}{Math.round(totalPL)}g for {qty})
</div>
```

**Purchase provenance (TRD-03):**
Below the P&L indicator, show where cargo was bought. Handle multiple batches:
```tsx
{cargoForGood.map((batch, i) => {
  const portLabel = batch.boughtAtPort.charAt(0).toUpperCase() + batch.boughtAtPort.slice(1).replace(/_/g, ' ');
  const turnLabel = batch.boughtAtTurn != null ? `, turn ${batch.boughtAtTurn}` : '';
  return (
    <div key={i} style={{ ...SUBTEXT, fontSize: '0.65rem', opacity: 0.8 }}>
      {batch.quantity}x bought at {portLabel} for {batch.boughtAtPrice}g{turnLabel}
    </div>
  );
})}
```

**Dynamic total P&L update (TRD-02):**
The `totalPL` variable already uses `qty` (from `getQty(good.id)`), which updates when the stepper changes. React re-renders automatically, so the total P&L preview updates dynamically as quantity changes. No additional state needed.

**Edge cases:**
- `boughtAtPort: 'salvaged'` -- the charAt(0).toUpperCase() + slice(1) approach handles this naturally, displaying "Salvaged"

- `profitPerUnit === 0` -- displayed in neutral color '#7a5c45' (existing SUBTEXT color)
- Player has no cargo of this good -- P&L section not rendered (guarded by `carried > 0`)
