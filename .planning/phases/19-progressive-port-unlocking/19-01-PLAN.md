       ```typescript
       // v9 (index 8): Add status column to port_access for three-tier access model
       (db) => {
         db.prepare("ALTER TABLE port_access ADD COLUMN status TEXT NOT NULL DEFAULT 'unknown'").run();
         // Backfill: any row with discovered=1 gets status='unlocked' (v1.3 upgrade path — all existing ports are fully unlocked)
         db.prepare("UPDATE port_access SET status = 'unlocked' WHERE discovered = 1").run();
       },
       ```

       ```sql
       INSERT INTO port_access (port_id, status, discovered, unlock_method)

       ON CONFLICT(port_id) DO UPDATE SET
         status = CASE WHEN port_access.status = 'unknown' THEN 'discovered' ELSE port_access.status END,
         discovered = 1
       ```

       c. `setPortAccessLevel(db, portId, status, unlockMethod?)` -> void: Upserts port_access row. Uses ON CONFLICT to only UPGRADE status (unknown->discovered->unlocked), never downgrade. Per decision from Phase 17-02.

          - miletus: status='discovered', unlock_method='starting_port'
          All other ports get no row (defaults to 'unknown' via getPortAccessLevel).

       e. `autoDiscoverPort(db, portId, turn)` -> boolean: If port is 'unknown', upgrades to 'discovered' with discovered_turn=turn and unlock_method='visited'. Returns true if upgraded. No-op and returns false if already discovered/unlocked.
