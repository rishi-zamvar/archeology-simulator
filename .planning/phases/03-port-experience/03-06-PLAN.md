  <name>Task 1: Create useGeneratedAmbient hook with synthesized soundscape</name>
  <files>src/renderer/hooks/useGeneratedAmbient.ts</files>
  <action>
    Create `src/renderer/hooks/useGeneratedAmbient.ts`. This module synthesizes a looping ambient Mediterranean port soundscape using Web Audio API — no file fetches, no external dependencies.

    **Module structure:** Mirror the singleton pattern from useAudioManager.ts (module-level object, not a React stateful hook). The hook just returns the singleton.

    **Soundscape design — 4 layered Web Audio nodes:**

    1. **Ocean waves** — filtered noise:
       - Create `OscillatorNode` with type `'sawtooth'`, frequency 0.15 Hz (very slow undulation)
       - Create `BiquadFilterNode` type `'lowpass'`, frequency 400, Q 0.7
       - Create a noise source: buffer of 2 seconds at sample rate filled with `Math.random() * 2 - 1` white noise
       - `BufferSourceNode` loop=true → `BiquadFilterNode`(lowpass 600Hz, Q 1.2) → GainNode(0.15) → destination
       - LFO (OscillatorNode 0.15Hz) → gain of a second GainNode that modulates the noise gain ±0.08, creating a wave rhythm

    2. **Wind drone** — detuned oscillators:
       - Two `OscillatorNode` instances, type `'sine'`
       - Frequencies: 55 Hz and 58 Hz (slight beating creates shimmer)
       - Each → GainNode(0.04) → `BiquadFilterNode` type `'bandpass'` frequency 55 Q 0.5 → destination
       - These create a low, distant wind hum

    3. **Seagull-like calls** — periodic short chirps (optional, keep simple):
       - A third oscillator type `'sine'`, frequency 1200 Hz, gain 0
       - Use `setValueAtTime` + `linearRampToValueAtTime` scheduled events to create 3-second periodic chirp envelopes (0 → 0.05 over 0.1s, hold 0.2s, → 0 over 0.3s)
       - Schedule the next chirp recursively after random 8-15 second intervals using `AudioContext.currentTime`
       - If scheduling complexity exceeds ~20 lines, skip this layer and use only waves + wind

    4. **Master gain** with fade-in:
       - All nodes route through a master GainNode, initial value 0
       - `linearRampToValueAtTime(0.6, context.currentTime + 3)` — 3-second fade in

    **Interface:**
    ```ts
    const GeneratedAmbientManager = {
      context: null as AudioContext | null,
      playing: false,

      async start(): Promise<void> {
        // ... create all nodes, start them
      },

      suspend(): void {
        // suspend context
      },
    };
    ```

    **visibilitychange handler** (same as useAudioManager):
    ```ts
    if (typeof document !== 'undefined') {
      document.addEventListener('visibilitychange', () => {
        if (!document.hidden && GeneratedAmbientManager.context?.state === 'suspended') {
          GeneratedAmbientManager.context.resume().catch(() => {});
        }
      });
    }
    ```

    **Exported hook:**
    ```ts
    export function useGeneratedAmbient(): typeof GeneratedAmbientManager {
      return GeneratedAmbientManager;
    }
    ```

    **Error handling:** wrap all of `start()` in try/catch. Any Web Audio error logs a warning and returns silently. Never throws to caller.

    **AudioContext creation guard:** check `window.AudioContext` exists before creating. Some Electron builds may have it under `webkitAudioContext`. Use the same pattern as useAudioManager: `window.AudioContext || (window as any).webkitAudioContext`.
