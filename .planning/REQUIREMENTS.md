# Requirements: v2.1 Immersion & Polish

## Visual Immersion

- [ ] **VIS-01**: Port scenes have parallax depth — foreground elements shift slightly with mouse movement
- [ ] **VIS-02**: Ambient particles per port (dust motes in Egypt, fireflies in Greek harbors, seagulls over coastal scenes)
- [ ] **VIS-03**: Day/night tinting based on current turn/season (golden hour, dusk blue-purple, midday bright)
- [ ] **VIS-04**: Map fog burns away when discovering new ports (parchment reveal animation)
- [ ] **VIS-05**: Vignette border on port scenes (dark edges like looking through a ship's porthole)

## Audio

- [ ] **AUD-01**: Port-specific ambient sounds (marketplace chatter for Athens, harbor bells for Ostia, waves for coastal ports)
- [ ] **AUD-02**: Sailing sounds (creaking wood, waves, wind intensity matching weather/season)
- [ ] **AUD-03**: UI sound effects (coin clink on trade, parchment unfurl on panels, quill scratch on journal entries)

## Animation & Effects

- [ ] **FX-01**: Typewriter effect on NPC dialogue text (characters appear one by one)
- [ ] **FX-02**: Wax seal stamp animation on quest completion
- [ ] **FX-03**: Parchment tear/unfurl animation when opening Harbor/Market popup
- [ ] **FX-04**: Gold coin counting animation visible when completing trades
- [ ] **FX-05**: Smooth screen transitions with CSS animations between all game states

## Gameplay Depth

- [ ] **GAME-01**: NPC rumors at ports ("I heard silver is cheap in Iberia this season") — hints for profitable trades
- [ ] **GAME-02**: Seasonal port festivals affecting economy ("The Panathenaia doubles pottery prices in Athens")
- [ ] **GAME-03**: Ship wear — hull condition degrades over voyages, requiring port stops for repairs
- [ ] **GAME-04**: Crew morale system affected by successful trades, long voyages, and events
- [ ] **GAME-05**: Historical postcards — collectible illustrations unlocked at each new port, viewable in journal

## Narrative

- [ ] **NAR-01**: NPC memory — NPCs remember your trades and comment on them
- [ ] **NAR-02**: Port gossip — NPCs share news about events at other ports
- [ ] **NAR-03**: Ending epilogue — narrated summary of entire journey with stats woven into historical narrative
