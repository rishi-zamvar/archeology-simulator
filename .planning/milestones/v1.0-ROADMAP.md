# Milestone v1.0: MVP

**Status:** SHIPPED 2026-03-12
**Phases:** 1-3
**Total Plans:** 13

## Overview

Build a turn-based ancient Mediterranean trade simulator as an Electron + React desktop app. Three phases deliver the project: Foundation establishes the cross-platform infrastructure and secure IPC bridge; Core Loop implements the game engine, map, trade mechanics, and turn system so the game is playable; Port Experience adds illustrated port scenes, museum artifact images, audio, and a guided tutorial so the educational experience is complete and shippable.

## Milestone Summary

**Key Decisions:**
- Electron 35 + Vite 7 + React 19 + better-sqlite3 stack
- GameState as discriminated union for type-safe FSM
- contextBridge IPC with window.api pattern
- Tailwind CSS 4 with inline styles for animations
- Leaflet + leaflet.motion for map and ship animation
- FIFO sell across cargo stacks for P&L granularity
- Web Audio API synthesis over file-based audio
- SVG illustrations over external image files for ports
- Met Museum API with SQLite artifact_cache (24h TTL)

**Issues Resolved:**
- better-sqlite3 version pinned to 12.6.2 (12.7.0 doesn't exist)
- Vite pinned to 7.3.1 (Vite 8 not released)
- leaflet.motion type casting pattern for missing TS bindings
- ArtifactImage orphaned component wired into TradePanel via gap closure
- Missing port PNG assets replaced with programmatic SVG scenes
- Missing audio MP3 replaced with Web Audio API synthesis

**Technical Debt Incurred:**
- CI workflow not yet triggered (needs GitHub remote + first push)
- ShipMarker has leaflet.motion typing workarounds
- Only 5 ports seeded (plan called for 25)
- Google Fonts loaded from CDN in dev (should bundle for offline)
