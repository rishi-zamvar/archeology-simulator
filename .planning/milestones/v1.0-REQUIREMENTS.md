**Archived:** 2026-03-16
**Status:** SHIPPED

This is the archived requirements specification for v1.0.

## v1 Requirements

### Map & Navigation (MAP)

- [x] **MAP-01**: Interactive Leaflet map displays the Mediterranean with parchment-style tile overlay (sepia filter, texture)
- [x] **MAP-02**: ~20-30 ports plotted at historically accurate coordinates sourced from Pleiades gazetteer
- [x] **MAP-03**: Ports display ancient names as primary labels with modern names in parentheses
- [x] **MAP-04**: Player can click a port to see its info panel (name, description, available goods, cultural context)
- [x] **MAP-05**: At each port, app shows 3-5 reachable destinations with distance and basic risk info

### Trade & Economy (TRADE)

- [x] **TRADE-01**: Each port produces and consumes specific goods based on historical trade patterns
- [x] **TRADE-02**: Player can buy and sell goods at each port with visible prices
- [x] **TRADE-03**: Prices fluctuate based on supply/demand simulation with historical exchange ratios as baseline
- [x] **TRADE-04**: Player has a running profit/loss display and transaction history
- [x] **TRADE-05**: Currency/barter differences by region are reflected in trade UI (informational)

### Ship & Inventory (SHIP)

- [x] **SHIP-01**: Player has a ship with cargo capacity limit
- [x] **SHIP-02**: Inventory UI shows current cargo, remaining space, and value of goods
- [x] **SHIP-03**: Ship has basic stats: speed and cargo capacity (one ship type for v1)

### Turn System (TURN)

- [x] **TURN-01**: Game is turn-based — each turn the player sails from one port to another
- [x] **TURN-02**: Player picks a start year in the 600-900 BCE range; time advances based on voyage distance
- [x] **TURN-03**: Ship animates along the route on the map between ports
- [x] **TURN-04**: Voyage events (storms, pirates, calm seas) can interrupt travel with decision cards
- [x] **TURN-05**: Hand-written event database with ~20-30 historically grounded events

### Port Experience (PORT)

- [x] **PORT-01**: Arriving at a port shows illustrated scene with clickable elements (market, harbor)
- [x] **PORT-02**: Side panels slide in for marketplace, port info, and cultural description
- [x] **PORT-03**: Cultural descriptions pulled from academic sources and rewritten for student accessibility
- [x] **PORT-04**: Museum artifact images from Met Museum API displayed for trade goods, with Wikimedia fallback

### Persistence (SAVE)

- [x] **SAVE-01**: Game auto-saves state to SQLite on every turn
- [x] **SAVE-02**: Player can resume from where they left off on next launch

### Tutorial (TUT)

- [x] **TUT-01**: Guided first voyage teaching map navigation, buying/selling, and sailing
- [x] **TUT-02**: Tutorial is skippable

### UI & Audio (UI)

- [x] **UI-01**: Parchment/ancient aesthetic throughout
- [x] **UI-02**: Side panel layout — map fills screen, info panels slide in from sides
- [x] **UI-03**: Ambient Mediterranean audio and sound effects
- [x] **UI-04**: Accessible UI: clear buttons, readable fonts

### Infrastructure (INFRA)

- [x] **INFRA-01**: Packaged as Electron app with installers for macOS, Windows, and Linux
- [x] **INFRA-02**: Distributed via GitHub releases
- [x] **INFRA-03**: JSON files for static reference data; SQLite for game state
- [x] **INFRA-04**: Critical images bundled with app; supplementary images cached on first load
- [x] **INFRA-05**: Game engine runs in Electron main process; React UI in renderer communicates via IPC
